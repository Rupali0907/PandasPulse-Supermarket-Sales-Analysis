# PandasPulse-Supermarket-Sales-Analysis
Python &amp; Pandas project for analyzing supermarket sales data. Performed data cleaning, exploration, and sales analysis to identify key business insights. Exported cleaned and analyzed results into CSV files.

# 🛒 PandasPulse – Supermarket Sales Analysis

## 📌 Overview

PandasPulse is a **Python & Pandas** project that analyzes supermarket sales data to extract useful business insights.

## 🛠️ Technologies

* Python
* Pandas
* VS Code

## 📊 Key Operations

* Data loading and exploration
* Missing value & duplicate handling
* Data cleaning and formatting
* Sales analysis by city, branch & product line
* Payment and gender analysis
* Customer rating analysis
* Data filtering, grouping & sorting
* Exporting analysis results to CSV

## 📂 Project Structure

```text
PandasPulse/
├── data/
├── output/
├── analysis.py
├── README.md
├── requirements.txt
└── .gitignore
```

## ▶️ Run

```bash
python analysis.py
```

The processed datasets and analysis results are generated in the `output/` folder.

## 📈 Outcome

The project helps identify **sales trends, customer behavior, payment preferences, and top-performing product categories** using Pandas.
